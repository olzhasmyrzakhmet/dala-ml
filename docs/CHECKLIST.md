# Ручной прогон на телефоне — 10 пунктов

Прогон делается на **реальном Android-телефоне**, а не в эмуляторе: тач, шрифты и
поведение service worker там отличаются. Открывать https://dala-ml.vercel.app

Отмечай `[x]` только то, что увидел своими глазами.

## 1. Первый экран
- [ ] Главная открылась меньше чем за 3 секунды на мобильном интернете.
- [ ] Виден живой виджет «Арық»: капля движется сама, без нажатий.
- [ ] Нет горизонтального скролла: страница не ездит вбок пальцем.

## 2. Ползунки пальцем
- [ ] Тянешь «Оқу жылдамдығы» пальцем — значение и картинка меняются, пока палец на экране.
- [ ] Ползунок не «срывается» при вертикальном скролле страницы.
- [ ] Попасть в ползунок легко с первого раза (не нужно целиться).

## 3. Три сценария «Арық»
- [ ] Оқу жылдамдығы 0.08 → появляется жёлтый статус «Локалды минимумда».
- [ ] 0.35 → появляется бирюзовый «Жинақталды».
- [ ] 0.70 → появляется красный «Шектен шықты», потом виджет сам перезапускается.

## 4. Жер еңісі меняет картину
- [ ] Тянешь «Жер еңісі» вправо — рельеф на глазах становится круче.
- [ ] На еңіс 2.0 тот же шаг 0.35, который раньше сходился, теперь ломается.

## 5. Казахский текст
- [ ] Все буквы ә ғ қ ң ө ұ ү і видны, ни одного квадратика.
- [ ] Ни одного русского слова в интерфейсе (кнопки, статусы, подписи).
- [ ] Заголовки не обрезаются посреди слова.

## 6. Урок целиком
- [ ] Урок «Арық: модель қалай оқиды» читается за ≤ 12 минут и понятен.
- [ ] Ни одного экрана подряд без картинки или интерактива.
- [ ] Формулы не ломают вёрстку: длинная формула скроллится внутри своей рамки.

## 7. Квиз и прогресс
- [ ] В квизе 3–5 вопросов, у каждого варианта есть разбор — и у верного, и у неверного.
- [ ] После квиза виден процент.
- [ ] Перезагрузил страницу — вверху осталась отметка «Өтілді».
- [ ] Вернулся на главную — там карточка «Жалғастыру» с названием этого урока.

## 8. Офлайн
- [ ] На `/kurs` нажал «Жүктеу» у 3-го модуля — появилось «Жүктелді».
- [ ] Включил авиарежим.
- [ ] Перезагрузил урок 3-го модуля — урок открылся.
- [ ] Виджет в офлайне живой: капля движется, ползунки работают.
- [ ] Сверху видна жёлтая полоса «Интернет жоқ».

## 9. Установка приложения
- [ ] Меню браузера → «Добавить на главный экран» доступно.
- [ ] Иконка на рабочем столе не пустая (виден жёлтый арык с бирюзовой каплей).
- [ ] Приложение открывается без адресной строки.

## 10. Отладки нет на витрине
- [ ] Внизу главной нет блока «Қазақша глифтер».
- [ ] Адрес `dala-ml.vercel.app/dev/widgets` не открывается (перебрасывает на главную).
- [ ] Нигде не видно `undefined`, `NaN`, пустых счётчиков «0 / 0».
