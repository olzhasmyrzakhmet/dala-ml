# PLAN — сборка «Дала ML». Сверху вниз. `[x]` только после «Проверка:».

Правило фазы: все чекбоксы + build/test зелёные + **критик** (≤3 циклов) + деплой +
prod-verify зелёный (включая прежние проверки) → фаза закрыта → commit.
Приоритет при нехватке времени: фазы 0–4 обязательны, фаза 5 — контент (можно 3 модуля вместо 8),
фаза 6 — усилители, режутся снизу.
