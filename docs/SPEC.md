## §3. Модель контента (MDX)
Frontmatter урока:
```yaml
---
module: 3
lesson: 2
slug: aryq-gradient
title: "Арық: модель қалай оқиды"
titleRu: "Арык: как модель учится"     # для навигации разработчика, на сайте не показывается
minutes: 11
metaphor: "aryq"                        # id виджета
concepts: ["gradient_descent", "learning_rate", "local_minimum"]
terms: ["градиенттік түсу", "оқу жылдамдығы"]   # связь со словарём
---
```
Тело урока строго по ритму (компоненты-обёртки):
`<Metaphor>` (степной образ + виджет) → `<Intuition>` (объяснение простыми словами) →
`<Formal>` (формула/термин, англ. оригинал в скобках) → `<Code>` (опционально) → `<Quiz>`.
Правило: **ни одного экрана подряд без визуала**. Абзац > 5 строк — разбей.

Словарь `glossary.json`: `{ kk, en, ru, short, metaphor, moduleRef, lessonSlug }`. Минимум 60 записей.

## §4. Восемь интерактивов — контракт и поведение
Общее: чистый Canvas 2D (или SVG для простых), React-обёртка, props `{ initial, onChange? }`,
никаких внешних чарт-библиотек. Управление: 1–2 ползунка + кнопка «Қайтадан» (сброс).
Каждый работает пальцем, `prefers-reduced-motion` уважается, ≤16мс на кадр на среднем Android.
**У каждого виджета — двухпанельный принцип: слева метафора (вода, отара, юрта), справа —
настоящий график/цифры. Двигаешь в метафоре — меняется в науке.** Это и есть моат, не экономь тут.

1. **AryqGradient** — вода стекает по рельефу в арык. Ползунки: `уклон` (крутизна функции),
   `ағын жылдамдығы` (learning rate). Справа — точка на кривой потерь. Демонстрируй три исхода:
   сходится / застрял в ямке (локальный минимум) / перелетел русло (расходимость).
2. **ZhailauQystau** — точки-овцы на «жайлау» (train) и «қыстау» (test). Кнопка «Проверить на
   қыстау» → показывает разницу ошибок.
3. **TangbaClassify** — ставишь тавро двух видов на поле; граница решения перерисовывается
   мгновенно. Ползунок — «строгость» (регуляризация).
4. **OtarBatch** — размер отары (batch size) → траектория обучения дрожит или плавная.
5. **KiizUiLayers** — собираешь юрту слой за слоем; каждый слой добавляет способность разделять
   более сложную границу (визуально — от прямой к кривой).
6. **DalaZheliNoise** — ползунок «ветер» добавляет шум в данные; смотришь, как модель сбивается.
7. **OverfitField** — увеличиваешь сложность модели: сначала лучше, потом кривая начинает
   «запоминать» шум. Два графика: train-ошибка вниз, test-ошибка вверх — момент перелома подсвечен.
8. **FeaturePrimeta** — выбираешь «приметы» (признаки): облака, ветер, поведение скота → точность
   прогноза дождя меняется. Показывает, что признаки решают больше, чем модель.

## §5. Прогресс без регистрации (lib/progress.ts)
localStorage-ключ `dala:progress:v1` = `{ lessons: {slug: {done, score, at}}, lastSlug, downloadedModules: [] }`.
Хук `useProgress()`. На главной — карточка «Жалғастыру» (продолжить) с последним уроком.
Экспорт/импорт прогресса JSON-файлом (страховка от потери — учитывая историю проекта, это уместно).

## §6. PWA и офлайн
Service worker: precache оболочки; по кнопке «Модульді жүктеу» — кэшируются MDX-страницы модуля,
его виджеты и ассеты. Индикатор офлайн-режима в шапке. Страница `/offline` для неподготовленных
маршрутов. Manifest: имя, иконки 192/512, `display: standalone`, тема `#12140F`.
**Проверка (обязательная, руками):** скачал модуль → DevTools Network Offline → перезагрузил →
урок и интерактив работают.

## §7. Песочница с кодом (P1, только после P0)
Pyodide через ленивый `import()` строго по клику «Кодты іске қосу» с честным предупреждением
о весе. До загрузки — статичный вывод заранее посчитанного примера, чтобы урок был полноценным
без кода. Никогда не грузить Pyodide автоматически.

## §8. Квизы (lib/quiz.ts)
3–5 вопросов на урок. Формат: вопрос, 3–4 варианта, **разбор для каждого варианта** (почему
неверно — это учебная ценность, а не «Неправильно!»). Результат в прогресс. Повтор разрешён.

7) Нет ссылок-404: собрать все внутренние ссылки с главной и /kurs → каждая 200;
8) HTML главной содержит казахские глифы `ә ғ қ ң ө ұ ү і` (кодировка не побита).
