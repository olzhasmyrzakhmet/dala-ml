# PRD — «Дала ML» (ML for the Steppe)
**Первая платформа машинного обучения на казахском языке**
Версия 1.0 · статус: готово к разработке

---

## 1. Видение

**Питч в одном предложении:** «Дала ML» — интерактивная платформа, которая объясняет машинное
обучение на казахском языке через образы, которые сельский школьник уже знает с детства: арыки,
отары, жайлау и кыстау, — и даёт потрогать каждую идею руками прямо в браузере, даже без интернета.

**Почему это существует.** Полноценного курса ML на казахском языке нет. Существующие материалы —
это либо английский (барьер), либо машинный перевод русских текстов (мёртвая терминология,
которую никто не использует в речи). Сельский школьник из Кызылординской области отсекается
дважды: языком и абстракцией.

**Что уже доказано:** курс проведён вживую, 231 ученик из сельских районов. Платформа — это
масштабирование того, что уже сработало офлайн.

---

## 2. Пользователь

**Основной:** школьник 9–11 класса из районного центра или села. Казахский — родной, английский —
слабый. Устройство — недорогой Android-телефон, реже школьный ноутбук. Интернет — мобильный,
нестабильный, лимитированный по трафику. Опыт программирования — нулевой или Pascal в школе.

**Вторичный:** учитель информатики, которому нужен готовый материал на казахском для кружка.

**Три следствия из этого портрета (определяют всю архитектуру):**
1. **Mobile-first, не «адаптивно потом».** Основной экран — 360–390px.
2. **Офлайн — не фича, а требование.** Модуль скачивается и работает без сети.
3. **Ноль установки.** Ни Python, ни Anaconda, ни регистрации. Открыл ссылку — учишься.

## 3. Моат: почему это не «ещё один курс»

### 3.1. Метафорический движок «Дала-аналогии» — ядро дифференциации
Каждая ML-концепция объясняется через степной образ, и это **не картинка для красоты, а
интерактивная модель**: ученик двигает ползунок в метафоре — и синхронно меняется настоящий
график/формула рядом.

| ML-концепт | Дала-метафора | Что делает ученик |
|---|---|---|
| Градиентный спуск | **Арық**: вода ищет путь вниз по склону | Меняет уклон и «скорость потока» (learning rate) — видит, как вода застревает в ямке (локальный минимум) или перелетает русло (расходимость) |
| Обучающая / тестовая выборка | **Жайлау и қыстау** | Пасёт отару на летнем пастбище, проверяет на зимнем — видит, что «выученное» не всегда работает на новом месте |
| Переобучение | Чабан **выучил одно поле наизусть** | Увеличивает сложность модели — видит, как она запоминает шум вместо закономерности |
| Классификация | **Таңба** (тавро на скоте) | Расставляет тавро — граница решения перерисовывается на глазах |
| Батч и эпоха | **Отар** и **сезонная кочёвка** | Меняет размер отары — видит дрожание/скорость обучения |
| Признаки (features) | Чабан читает **погоду по приметам** | Выбирает приметы — точность прогноза меняется |
| Шум в данных | **Дала желі** (степной ветер) | Добавляет ветра — смотрит, как модель сбивается |
| Слои сети | Сборка **киіз үй** (юрты) | Собирает каркас по частям — каждая часть держит свою нагрузку |

**Почему это защищает от конкурентов.** Перевести курс может любой. Построить систему объяснений,
где термин рождается из культурного опыта ученика, — это работа, которую нельзя сделать
автопереводом. Это и есть настоящий контентный моат.

### 3.2. Казахско-английский словарь ML-терминов
Отдельный публичный раздел: термин на казахском, английский оригинал, объяснение в одну строку,
степная аналогия, произношение. Первый в своём роде ресурс — общественное благо, точка входа из
поиска и артефакт, на который ссылаются учителя.

### 3.3. Офлайн-режим (PWA)
Ученик в поле без сети открывает скачанный модуль и продолжает. Прогресс синхронизируется, когда
сеть появится. Для сельского Казахстана это разница между «курс есть» и «курса нет».

### 3.4. Нулевой порог входа
Код запускается в браузере. Прогресс хранится локально — без регистрации, без email, без пароля.
Сертификат генерируется на устройстве.

## 4. Структура курса (8 модулей, ~22 недели)

Каждый модуль = 3–4 урока. Каждый урок собран по одному ритму:
**Метафора → Интуиция → Интерактив → Код → Проверка себя**

| # | Модуль (каз.) | Содержание |
|---|---|---|
| 1 | **Мәліметтер** (Данные) | Что такое данные, признаки, таблица, чистка. Метафора: перепись отары |
| 2 | **Заңдылық іздеу** (Поиск закономерности) | Линейная регрессия. Метафора: предсказать удой по приметам |
| 3 | **Арық: оқыту** (Обучение) | Функция потерь и градиентный спуск. Метафора: вода по арыку |
| 4 | **Таңба: жіктеу** (Классификация) | Логистическая регрессия, граница решения. Метафора: тавро |
| 5 | **Жайлау мен қыстау** (Обобщение) | Train/test, переобучение, валидация |
| 6 | **Киіз үй: нейрондық желі** (Нейросети) | Персептрон, слои, активации. Метафора: сборка юрты |
| 7 | **Көру** (Компьютерное зрение) | Свёртки на простых примерах: распознать тавро, породу |
| 8 | **Жоба** (Проект) | Свой мини-проект на локальных данных: урожай, погода, скот |

**Правило контента:** ни один урок не длиннее 12 минут чтения. Ни одного абзаца без визуала
или интерактива.

## 5. Функциональные требования

### P0 — ядро (без этого продукта нет)
- **F1. Метафорический интерактив.** ≥8 интерактивных виджетов (по одному ключевому на модуль),
  чистый Canvas/SVG, работают на телефоне, без тяжёлых библиотек, 60fps на слабом устройстве.
- **F2. Уроки.** Контент в MDX, единый ритм секций, оглавление, прогресс-бар модуля.
- **F3. Прогресс без регистрации.** localStorage/IndexedDB: пройденные уроки, ответы на квизы,
  продолжить с места остановки.
- **F4. Проверка себя.** 3–5 вопросов в конце урока (варианты + разбор ответа, не просто «верно/неверно»).
- **F5. PWA офлайн.** Service worker, кнопка «Скачать модуль», индикатор офлайн-режима.
- **F6. Словарь терминов.** Поиск, фильтр по модулю, ссылка на урок.
- **F7. Мобильная вёрстка 360px** как основная, десктоп — расширение.

### P1 — усилители
- **F8. Песочница с кодом.** Python в браузере (Pyodide) — ленивая загрузка, только на уроках с
  кодом, с явным предупреждением о трафике и лёгким fallback (заранее посчитанные результаты).
- **F9. Сертификат.** Генерация PNG/PDF на устройстве по завершении курса.
- **F10. Режим экономии трафика.** Отключает тяжёлые ассеты, показывает статичные версии.
- **F11. Для учителя.** Страница с планом занятий и раздаточным материалом.

### P2 — потом
Русская и английская локализация интерфейса, лидерборд школ, разбор проектов учеников.

**Явно НЕ делаем в MVP:** аккаунты, бэкенд с базой, видео-хостинг, чат, мобильное приложение.

---

## 6. Метрика успеха

**Главная:** доля учеников, дошедших до конца модуля 3 («Арық») — первый по-настоящему сложный
момент курса. Если человек понял градиентный спуск через воду в арыке, он останется.

Вторичные: время до первого интерактива (<20 секунд от открытия), доля мобильных сессий,
количество скачанных офлайн-модулей, обращения к словарю.

---

## 7. Технические требования

- **Скорость:** первый экран < 2 секунд на 3G. Вес первой загрузки < 200 КБ (без Pyodide).
- **Работает без JS-фреймворковой магии на слабом железе:** статическая генерация, гидрация минимальна.
- **Доступность:** контраст AA, навигация с клавиатуры, фокус-стили, `prefers-reduced-motion`.
- **Совместимость:** Chrome/Android 90+, Safari iOS 15+.

---

## 8. Дизайн-манифест

**Эстетика:** современная степь, а не этнический китч. Спокойный тёмно-графитовый фон, тёплый
песочно-золотой акцент, глубокий бирюзовый (цвет воды в арыке) для интерактивных элементов.
Геометрия — намёк на казахский орнамент в разделителях и рамках, тонко, 1–2px, не ковёр.

**Типографика:** заголовки — гротеск с хорошей поддержкой казахской кириллицы (ә, ғ, қ, ң, ө, ұ,
ү, һ, і — проверить ВСЕ глифы), текст — читаемый на телефоне, 17–18px базовый.

**Тон:** уважительный, без сюсюканья и без академического снобизма. Обращение на «сен» —
как старший брат объясняет младшему у костра. Никаких «Привет! Сегодня мы изучим...».
Сразу к делу: «Су неге төмен ағады? Модель де солай оқиды.»

**Запрещено:** стоковые фото степи с закатом, эмодзи в заголовках, градиентные кнопки,
«ИИ-шный» лендинг из hero + трёх карточек с иконками.

## 9. Риски и ответы

| Риск | Ответ |
|---|---|
| Казахская ML-терминология не устоялась | Даём пару «казахский термин (English original)» везде при первом упоминании. Словарь — часть продукта, а не приложение |
| Pyodide тяжёлый для мобильного трафика | Ленивая загрузка только по явному клику + предупреждение о размере + fallback с готовыми результатами |
| Интерактивы тормозят на слабых телефонах | Canvas вместо DOM-анимаций, requestAnimationFrame, отключение частиц при `prefers-reduced-motion` и в режиме экономии |
| Контент — самая долгая часть | MVP: 3 модуля полностью + каркас остальных. Лучше 3 отличных, чем 8 сырых |
