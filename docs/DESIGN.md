# Дизайн-система «Дала ML»

> Современная степь. Не этнический китч.

## 1. Философия

Дизайн вырос из контекста: сельский школьник, дешёвый Android, степь за окном. 
Эстетика — спокойная, уважительная, без сюсюканья и без снобизма.

**Тон:** как старший брат объясняет младшему у костра. Обращение на «сен».

## 2. Цветовая палитра

### Фоны
| Название | HEX | Использование |
|----------|-----|---------------|
| `dala-bg` | `#12140F` | Основной фон — тёмный графит с землистым подтоном |
| `dala-surface` | `#1B1E17` | Поверхности карточек, секций |

### Текст
| Название | HEX | Использование |
|----------|-----|---------------|
| `dala-text` | `#EDEAE2` | Основной текст — тёплый белый |
| `dala-muted` | `#9A9B90` | Вторичный текст, подписи |

### Акценты
| Название | HEX | Использование |
|----------|-----|---------------|
| `dala-gold` | `#D9A441` | **Золото степи** — заголовки, прогресс, акценты |
| `dala-water` | `#3FA9A0` | **Вода арыка** — интерактивные элементы, ссылки, фокус |
| `dala-alert` | `#D9614C` | Тревога, ошибки |

### Границы
- Стандарт: `1px solid rgba(217, 164, 65, 0.18)` (золото 18%)
- Фокус: `2px solid #3FA9A0`

## 3. Типографика

### Шрифты
- **Заголовки и текст:** Inter с подмножеством `cyrillic-ext` (критично для қазақских глифов!)
- **Моноширинный:** JetBrains Mono или system monospace

**Важно:** При подключении через `next/font/google` обязательно указать:
```ts
const inter = Inter({ 
  subsets: ['latin', 'cyrillic-ext'], // ← cyrillic-ext для ұ ү қ ң ә
  display: 'swap',
})
```
Стандартный `cyrillic` не содержит казахских букв — будет «рябый» текст.

### Масштаб (mobile-first)
| Элемент | Размер | Высота строки | Вес |
|---------|--------|---------------|-----|
| H1 | 1.5rem (24px) | 1.2 | 700 |
| H2 | 1.25rem (20px) | 1.3 | 600 |
| H3 | 1.125rem (18px) | 1.4 | 600 |
| Body | 1rem (16px) | 1.7 | 400 |
| Small | 0.875rem (14px) | 1.5 | 400 |
| Caption | 0.75rem (12px) | 1.4 | 400 |

**Базовый размер на телефоне: 16px (не меньше для читаемости)**

### Казахские глифы
Обязательная проверка во всех начертаниях:
```
ә ғ қ ң ө ұ ү һ і
```
Ни одного квадрата. Если шрифт не тянет — меняем.

## 4. Сетка и отступы

### Контейнер
- Макс-ширина: `max-w-7xl` (1280px)
- Padding: `px-4` (16px) мобильный, `px-6` (24px) десктоп

### Отступы между секциями
- Маленький: `py-8` (32px)
- Средний: `py-12` (48px)
- Большой: `py-16` (64px)

### Гэп в сетках
- Стандарт: `gap-4` (16px)
- Увеличенный: `gap-6` (24px)

## 6. Интерактивные виджеты

### Двухпанельный принцип (ядро моата)
**Левая панель:** метафора (вода, отара, юрта)
**Правая панель:** настоящий график/формула

**Правило:** двигаешь в метафоре — меняется в науке. Синхронно.

### Canvas
- DPR-масштабирование для ретины
- `requestAnimationFrame` с отменой на unmount
- Поддержка `prefers-reduced-motion`
- Тач-события для телефонов

## 7. Анимации

### Микро-взаимодействия
- Hover кнопок: `transition-all duration-200`
- Фокус: `outline-2 outline-dala-water outline-offset-2`
- Нажатие: `scale-[0.98]`

### `prefers-reduced-motion`
```css
@media (prefers-reduced-motion: reduce) {
  * { animation-duration: 0.01ms !important; transition-duration: 0.01ms !important; }
}
```

## 8. Мобильные ограничения

### Зоны нажатия
- Минимум: 44×44px
- Расстояние между кликабельными: ≥8px

### Производительность
- Первый экран < 2 сек на 3G
- JS бандл < 200 КБ (без Pyodide)
- 60fps на виджетах

### Офлайн
- Service Worker для оболочки
- Кэширование модулей по запросу
- Индикатор статуса сети
