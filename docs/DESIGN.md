# Дизайн-система «Дала ML»

> Современная степь. Не этнический китч.

## 1. Философия

Дизайн вырос из контекста: сельский школьник, дешёвый Android, степь за окном. 
Эстетика — спокойная, уважительная, без сюсюканья и без снобизма.

**Тон:** как старший брат объясняет младшему у костра. Обращение на «сен».

## 3. Типографика

### Шрифты
- **Заголовки и текст:** Inter с подмножеством `cyrillic-ext` (критично для қазақских глифов!)
- **Моноширинный:** JetBrains Mono или system monospace

**Важно:** При подключении через `next/font/google` обязательно указать:
```ts
const inter = Inter({ 
  subsets: ['latin', 'cyrillic-ext'], // ← cyrillic-ext для ұ ү қ ң ә
  display: 'swap',
})
```
Стандартный `cyrillic` не содержит казахских букв — будет «рябый» текст.

### Масштаб (mobile-first)
| Элемент | Размер | Высота строки | Вес |
|---------|--------|---------------|-----|
| H1 | 1.5rem (24px) | 1.2 | 700 |
| H2 | 1.25rem (20px) | 1.3 | 600 |
| H3 | 1.125rem (18px) | 1.4 | 600 |
| Body | 1rem (16px) | 1.7 | 400 |
| Small | 0.875rem (14px) | 1.5 | 400 |
| Caption | 0.75rem (12px) | 1.4 | 400 |

**Базовый размер на телефоне: 16px (не меньше для читаемости)**

### Казахские глифы
Обязательная проверка во всех начертаниях:
```
ә ғ қ ң ө ұ ү һ і
```
Ни одного квадрата. Если шрифт не тянет — меняем.

### Slider — только нативный `input[type=range]`
```
Элемент: <input type="range">, высота элемента 44px (зона нажатия)
Трек: 8px, скруглённый; заполнение через CSS-переменную --pct
Thumb: 26px, обводка 3px цветом фона, свечение по акценту
Цвет: dala-water (по умолчанию), dala-gold для второго параметра
Состояния: hover scale 1.06, active scale 1.14 + кольцо 8px, focus-visible кольцо 6px
Стили: app/globals.css, класс .dala-range
```

**Свой ползунок на `<div>` делать запрещено.** Нативный элемент бесплатно даёт
тач-события, инерцию прокрутки, клавиатуру (стрелки, Home/End), скринридер,
системные настройки доступности и корректное поведение при перетаскивании за
пределы элемента. Всё это в самодельном варианте приходится писать заново — и
обычно оно оказывается сломанным.

Дискретный выбор (число слоёв, набор признаков) — компонент `Segmented`
с `role="radiogroup"`, кнопки не ниже 44px.

### Двухпанельная оболочка виджета (`WidgetFrame`)
```
Шапка: название + одна строка подсказки + кнопка «Қайтадан» (44px)
Панели: метафора и наука, встык через 1px золотой границы;
        на ≥640px рядом, на телефоне друг под другом
Показания: три ячейки <dl> под панелями, моноширинные цифры
Управление: ползунки и переключатели
Статус: role="status" aria-live="polite", тон ok / warn / bad со своей иконкой
```
Подписи показаний — **без `uppercase`**: он ломает `θ` и часть казахских глифов.
В моноширинных значениях не должно быть казахских слов: в JetBrains Mono
строчная «ә» рисуется почти как заглавная «Ә». Единицы измерения выносим
в подпись или подсказку.

## 6. Интерактивные виджеты

### Двухпанельный принцип (ядро моата)
**Левая панель:** метафора (вода, отара, юрта)
**Правая панель:** настоящий график/формула

**Правило:** двигаешь в метафоре — меняется в науке. Синхронно.

### Canvas
- **Ширина всегда по контейнеру** (ResizeObserver), высота — по соотношению.
  Фиксированная ширина в пикселях на 360px даёт горизонтальный скролл.
- DPR-масштабирование для ретины, потолок 2.5 — выше смысла нет, а батарея есть.
- `requestAnimationFrame` с отменой на unmount.
- Холст вне экрана **не рисует** (IntersectionObserver): восемь виджетов на одной
  странице не должны греть телефон.
- `prefers-reduced-motion`: декоративное время замирает (рябь, ветер, качание травы),
  но сама модель продолжает считаться — она и есть содержание урока.
- Указатель — единый `pointerdown/move/up` с `setPointerCapture`: один код на палец и мышь.

### Разделение симуляции и отрисовки
Состояние модели живёт в `useRef` и обновляется в своём кадре; холсты только читают.
Цифры под графиком синхронизируются с React ~12 раз в секунду (`useTelemetry`).
`setState` на каждый кадр запрещён: это 60 перерисовок дерева в секунду.

## 7. Анимации

### Микро-взаимодействия
- Hover кнопок: `transition-all duration-200`
- Фокус: `outline-2 outline-dala-water outline-offset-2`
- Нажатие: `scale-[0.98]`

### `prefers-reduced-motion`
```css
@media (prefers-reduced-motion: reduce) {
  * { animation-duration: 0.01ms !important; transition-duration: 0.01ms !important; }
}
```

## 8. Мобильные ограничения

### Зоны нажатия
- Минимум: 44×44px
- Расстояние между кликабельными: ≥8px

### Производительность
- Первый экран < 2 сек на 3G
- JS бандл < 200 КБ (без Pyodide)
- 60fps на виджетах

### Офлайн
- Service Worker для оболочки
- Кэширование модулей по запросу
- Индикатор статуса сети
