# Дала ML

Первая платформа машинного обучения на казахском языке.

## О проекте

«Дала ML» — интерактивная платформа, которая объясняет машинное обучение на казахском языке через образы, которые сельский школьник уже знает с детства: арыки, отары, жайлау и кыстау.

## Стек

- Next.js 14 + TypeScript
- Tailwind CSS
- Vitest + Playwright
- PWA (Service Worker)

## Команды

```bash
npm run dev      # Разработка
npm run build    # Сборка
npm run test     # Unit-тесты
npm run e2e      # E2E-тесты
npm run prod:verify  # Проверка продакшена
```

## Структура

```
app/          # Next.js App Router
components/   # React компоненты
content/      # MDX-уроки
lib/          # Утилиты
public/       # Статические файлы
scripts/      # Скрипты проверки
tests/        # Тесты
e2e/          # E2E-тесты
```
